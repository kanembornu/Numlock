# UI reconstruction

1. Read `CURRENT.md`, the surface blueprint, current markup, and named tests.
2. Capture production baseline at required viewport/theme/state.
3. Map keep/remove/move targets; change one surface only.
4. Preserve IDs, data, requests, state, accessibility, theme, print, and budgets.
5. Run focused checks, unified gate, then browser functional checks.
6. Use `visual-review.md`; update workspace/docs with evidence only.

Stop on missing baseline, ownership conflict, contract drift, or failed gate.
